# Avisos de terceros

Este documento registra **de dónde salió cada idea** que informó a los componentes de
`laravel-muni-ui`, y bajo qué licencia. Es un requisito del propio proceso de modernización: el
paquete se redistribuye a otras municipalidades bajo licencia privada, así que la procedencia tiene
que estar escrita, no recordada.

**Ningún archivo de este paquete contiene código, markup ni CSS copiado de las fuentes listadas.**
Lo que se toma de ellas es *comportamiento* (qué tecla hace qué, dónde va el foco, qué roles ARIA
corresponden) y *composición de página* (qué bloques forman una pantalla y en qué orden). El markup
se reescribe con nuestros componentes y nuestros tokens `--muni-*`.

## La reja de licencias

Regla aplicada al clonar, sin excepciones: solo **MIT, Apache-2.0, BSD o ISC**. Un repositorio sin
archivo de licencia en la raíz, o con licencia fuera de esa lista, se **borró sin leerlo**.
